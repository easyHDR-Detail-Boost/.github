## What Is easyHDR

easyHDR is a bracket helper for photos you took yourself. easyHDR bracket merge is the first job: several exposures of the same view become one file. easyHDR exposure align fixes a small handheld shift. A window in a home room, a classroom with mixed light, or a sunset from a trip are typical reasons to shoot more than one frame.

easyHDR tone map decides how bright the merged picture should look. easyHDR ghost removal matters when something moved, because a person between frames can leave a smear. easyHDR detail boost is a later choice, useful when the merge looks flat. The aim for home and study work is a natural picture, not a harsh outline around every leaf.

Shoot the brackets first, then open them together. Run easyHDR exposure align, then easyHDR bracket merge, and look for movement before you trust easyHDR ghost removal. Set easyHDR tone map gently, and add easyHDR detail boost only if the print or the slide still looks dull. Keep the original frames so you can merge again.

## Starting with easyHDR

Prerequisites: A compatible computer, two or more exposures of one scene, and permission to run easyHDR.

1. **Prepare:** Keep the dark, middle, and bright frames in one folder.
2. **Line Them Up:** Run easyHDR exposure align before you judge edges.
3. **Merge:** Start easyHDR bracket merge and look at the combined range.
4. **Check Motion:** Use easyHDR ghost removal if a person or a branch moved.
5. **Set Brightness:** Adjust easyHDR tone map until the room looks believable.
6. **Add Detail Last:** Try a light easyHDR detail boost only if the picture looks flat.
